# Achat-Revente · Ventes privées

Petit outil web (HTML/CSS/JS, sans installation) pour faire de l'achat-revente à partir des ventes privées (Veepee, Showroomprivé, Bazarchic…).

## Utilisation

Ouvre `index.html` dans un navigateur, ou publie le dépôt avec GitHub Pages.

- **Calculateur** : prix d'achat, port, commission de la plateforme, emballage et cotisations → bénéfice net, marge, ROI, prix de revente minimum et prix pour atteindre ta marge cible.
- **Stock & ventes** : suivi de chaque article (coût, statut, prix vendu, délai de vente), capital immobilisé, bénéfice, alerte à l'approche du seuil DAC7 (30 ventes / 2 000 € par an). Export/import CSV.
- **Guide** : choix des produits, pièges à éviter, cadre légal en France, routine conseillée.

Les données sont stockées localement dans le navigateur ; exporte-les en CSV pour les sauvegarder.
Les commissions et taux préremplis sont indicatifs : vérifie les tarifs en vigueur.
